# 行政后勤管理系统

## 简介

本系统最初为宿舍管理系统，后根据实际需求逐步扩展，加入更多后勤管理功能，遂更名为行政后勤管理系统。

- 开源项目，欢迎自行测试与反馈
- 支持自定义修改代码以满足个性化需求
- 已配置 GitHub Actions 自动打包发布，提交 `v*` 版本标签即可触发版本发布

## 下载地址

https://github.com/ccwy/dorm/releases

## 功能概览

- **人员管理** — 用户管理、角色权限控制
- **住宿管理** — 房间管理、床位管理、宿舍分配、退宿管理
- **设施与费用** — 房间设施管理、水电表抄表、水电费计算（含退宿结算）
- **合同管理** — 合同信息维护与跟踪
- **物资管理** — 低值易耗品进销存、供应商管理、存放位置管理、基础物料资料
- **资产管理** — 固定资产登记与盘点、后勤维修与盘点
- **协同办公** — OA 聊天、文件共享、待办事项、留言管理
- **系统配置** — 各模块可独立启用或关闭
- 更多功能持续开发中

## 支持系统

| 平台 | 版本要求 | 运行模式 |
|------|---------|---------|
| Windows 7 SP1 | 32/64 位 | 仅服务端模式 |
| Windows 10+ | 64 位 | 客户端 + 服务端模式 |
| Android 8+ | ARM64 / x86 | 客户端模式 |
| docker | AMD64  | 仅服务端模式 |

### 系统要求

- Windows 7 SP1（32 位或 64 位）及以上系统
- Windows 7 必须安装系统更新Win7 SHA-2代码签名支持 [KB4474419](https://catalog.update.microsoft.com/v7/site/Search.aspx?q=KB4474419)
- 服务端模式需安装现代浏览器（推荐 Chrome 109+ 或 Firefox 115 ESR）
- **不支持 IE浏览器**
- Windows 10 及以上需安装 [WebView2 运行时](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
- Android 8 及以上，支持 ARM64 和 x86 架构

### 系统环境检测工具

为方便用户在安装前检测系统环境是否满足运行要求，提供独立的系统环境检测工具：

- **功能**：检测系统是否已安装 WebView2 运行时及 Win7 SHA-2 代码签名支持（KB4474419）等必要组件
- **使用方式**：下载 Release 中的 `check_env_v*.exe`，双击运行即可查看检测结果
- **源码位置**：[`check_sh2_webviw2/`](check_sh2_webviw2/)

## 运行方式

### 发布包运行

- **Windows 端**：下载发布包后直接运行即可，支持客户端模式与服务端模式切换
- **Android 端**：下载发布包后直接安装运行即可
- **Docker 部署**：已提供 amd64 架构镜像，未上架docker平台，但有打包好，也可以自行通过源码打包，自行部署即可
- 启动加载内容较多，首次启动可能稍慢，请耐心等待

### 从源码运行

**环境要求**

- Python 3.8 及以上版本
- 推荐使用虚拟环境隔离项目依赖

**克隆项目**

```bash
git clone https://github.com/ccwy/dorm.git
cd dorm
```

**安装依赖**

```bash
pip install -r requirements.txt
```

**启动服务**

```bash
python main.py
```

启动后根据配置自动选择客户端模式（WebView 桌面窗口）或服务端模式（浏览器访问）。默认端口 `35168`，访问地址：

- 客户端模式：自动打开桌面窗口
- 服务端模式：`http://127.0.0.1:35168`

**可选参数**

| 参数 | 说明 |
|------|------|
| `--config <环境>` | 指定配置环境（默认 `default`） |
| `--no-reload` | 禁用自动重载 |

```bash
# 以生产配置启动
python main.py --config production --no-reload
```
