### 行政后勤管理系统

### 基本介绍

1，本系统原身是宿舍管理系统，后根据需要扩展开发加入更多功能后才改名
2，系统是否好用请自行测试
3，开源项目，您也可以自行修改代码
4，以设置好利用github自动打包发布，只需要提交v* 版本号即可触发版本发布

### 下载地址

https://github.com/ccwy/dorm/releases

### 功能简介
    - 支持用户管理
    - 支持房间管理
    - 支持宿舍分配管理
    - 支持宿舍水电费计算及管理
    - 支持角色管理，用于系统权限控制
    - 支持合同管理
    - 支持低值易耗品进销存管理
    - 支持后勤维修管理
    - 支持固定资产管理
    - 支持OA聊天
    - 支持文件共享
    - 支持待办事项管理
    - 支持留言管理
    - 更多功能待您发现


### 支持系统

    win7 - win11系统
    下载对应的系统版本即可

#### 系统要求
    - Windows 7 SP1（32位或64位）
    - 需要安装 VC++ 2015-2019 运行时（x86）
    - 建议安装 Windows 更新 KB2999226
    - 需要安装现代浏览器（Chrome 109+ 或 Firefox 115 ESR 推荐）
    - 仅支持服务器模式运行
    - **不支持 IE11**

### 正常版本
    - win10以上系统皆可使用
    - 需要安装WebView2 运行时
    - 需要安装VC++ 2015-2019 运行时库
    - 支持客户端模式和服务器模式

### 使用方式
    Windows端直接打开即可使用，支持切换服务端和客户端
    docker amd64打包文件已上传，自行部署即可
    启动可能较慢，耐心等待，因为加载的东西较多原因。
