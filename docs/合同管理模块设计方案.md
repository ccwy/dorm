# 合同管理模块设计方案

## 一、模块概述

基于现有行政后勤管理系统架构，新增合同管理模块，实现合同的创建、审批、履约跟踪、到期提醒等全生命周期管理。模块包含以下核心功能：

1. **合同基本信息管理**：合同编号、合同名称、甲乙双方（关联供应商）、合同金额、税率（支持从供应商自动获取并可自定义覆盖）、签订日期、起止日期、合同状态
2. **合同附件管理**：每条合同记录支持上传多个附件（合同扫描件、补充协议等），附件独立存储，支持增删查
3. **合同操作记录**：记录合同的创建、编辑、状态变更等操作，包含变更详情
4. **到期提醒**：合同列表页通过颜色标识和标签提醒即将到期/已到期的合同
5. **续签管理**：支持合同续签，通过自引用外键建立续签关系链，续签时自动关联原合同并复制基本信息

**核心定位**：合同管理模块与现有供应商管理模块深度集成，甲乙双方信息直接选用供应商数据，税率可从供应商自动获取，避免数据冗余，实现合同与供应商的关联追溯。同时支持合同续签关系链管理，实现合同全生命周期的连续性追踪。

## 二、架构设计原则

严格遵循项目现有架构模式：

### 2.1 Blueprint四层分层架构

| 层次 | 文件后缀 | URL前缀 | 蓝图变量命名 | 职责 |
|------|---------|---------|-------------|------|
| 主蓝图 | `contract.py` | `/contract` | `contract_bp` | 列表页+表单页(GET) |
| 操作蓝图 | `contract_operations.py` | 注册到主蓝图 | 无独立蓝图 | CRUD操作(POST) |
| API蓝图 | `contract_api.py` | `/api/contracts` | `contract_api_bp` | JSON响应 |
| 导入导出蓝图 | `contract_import_export.py` | `/contract/import-export` | `contract_import_export_bp` | Excel导入导出 |

**关键模式**：操作蓝图不创建独立Blueprint对象，路由直接注册到主蓝图上。操作蓝图文件顶部导入主蓝图：
```python
from .contract import contract_bp
@contract_bp.route('/operations/add', methods=['POST'])
```
主蓝图文件底部触发操作路由注册：
```python
from . import contract_operations
```

### 2.2 模型设计模式

- **命名**：蛇形命名法，一个模型类一个文件
- **表名**：复数形式（如 `contracts`, `contract_attachments`, `contract_operation_records`）
- **主键**：`id = db.Column(db.Integer, primary_key=True)`
- **时间戳**：`created_at` + `updated_at`（`default=datetime.now`, `onupdate=datetime.now`）
- **操作人**：`operator_user_id = db.Column(db.Integer, nullable=True)`
- **字段注释**：每个 `db.Column` 必带 `comment='中文说明'`
- **约束命名**：`uq_表名_字段名`（唯一）/ `check_约束描述`（检查）
- **索引命名**：`idx_表缩写_字段名`
- **关系定义**：`db.relationship` + `backref` + `cascade='all, delete-orphan'`
- **外键**：`db.ForeignKey('table.id', ondelete='CASCADE')`
- **类方法**：`create(cls, ...)`, `is_number_exists()`, `check_usage()`
- **属性方法**：`@property display_status` 等

### 2.3 子文件夹组织

由于项目根目录下模型和蓝图文件数量较多，本模块采用子文件夹组织：

**模型子文件夹**: `models/contract/`
- 创建 `models/contract/__init__.py` 作为包初始化文件，导出所有模型类
- 所有模型文件放在 `models/contract/` 子文件夹内
- `models/__init__.py` 新增：`from .contract import Contract, ContractAttachment, ContractOperationRecord`

**蓝图子文件夹**: `blueprints/contract/`
- 创建 `blueprints/contract/__init__.py` 作为包初始化文件，导出所有蓝图变量
- 所有蓝图文件放在 `blueprints/contract/` 子文件夹内
- 操作蓝图导入主蓝图时使用相对导入：`from .contract import contract_bp`
- `blueprints/__init__.py` 新增：`from .contract import contract_bp, contract_api_bp, contract_import_export_bp`

### 2.4 编号规则

| 单据类型 | 编号前缀 | 格式 | 示例 |
|---------|---------|------|------|
| 合同编号 | HT | HT+年月+4位序号 | HT2026080001 |

### 2.5 其他原则

- **配置驱动**: 功能开关从`SystemConfig`读取，合同类型、合同状态等从系统配置获取
- **操作日志**: 同时调用`log_operation`写入`OperationLog`，并写入专用操作记录表（`ContractOperationRecord`）记录变更详情
- **权限控制**: `require_permission`装饰器 + `login_required`认证，权限码为 `contract.view`, `contract.create` 等
- **删除验证**: 删除前检查合同是否有关联附件或操作记录，提供级联删除选项
- **前端技术栈**: TailwindCSS + FontAwesome + Jinja2模板
- **导入导出模式**: 参照`supplier_import_export.py`，使用pandas + openpyxl实现Excel导入导出
- **附件上传**: 参照`AssetPhotoManager`的文件管理模式，创建`ContractAttachmentManager`工具类

```python
from datetime import datetime, date, timedelta
from decimal import Decimal
from utils.db import db


class Contract(db.Model):
    """合同主表"""
    __tablename__ = 'contracts'

    # 核心字段
    id = db.Column(db.Integer, primary_key=True)
    contract_number = db.Column(db.String(50), unique=True, nullable=True, comment='合同编号（允许自定义，留空自动生成）')
    contract_name = db.Column(db.String(255), nullable=False, comment='合同名称')

    # 甲乙双方（关联供应商表）
    party_a_id = db.Column(db.Integer, db.ForeignKey('suppliers.id', ondelete='SET NULL'), nullable=True, comment='甲方供应商ID')
    party_b_id = db.Column(db.Integer, db.ForeignKey('suppliers.id', ondelete='SET NULL'), nullable=True, comment='乙方供应商ID')

    # 合同类型与分类
    contract_type = db.Column(db.String(50), nullable=True, comment='合同类型（从系统配置读取，如：采购合同/服务合同/租赁合同/其他）')
    contract_category = db.Column(db.String(50), nullable=True, comment='合同分类（从系统配置读取）')

    # 金额信息
    contract_amount = db.Column(db.Numeric(14, 2), default=Decimal('0.00'), nullable=True, comment='合同金额（元）')
    currency = db.Column(db.String(10), default='CNY', nullable=True, comment='币种')

    # 税率信息
    tax_rate = db.Column(db.Numeric(5, 2), nullable=True, comment='合同税率（%，可从供应商自动获取，支持自定义覆盖）')

    # 日期信息
    signing_date = db.Column(db.Date, default=date.today, nullable=True, comment='签订日期（默认当天）')
    start_date = db.Column(db.Date, default=date.today, nullable=True, comment='合同开始日期（默认当天）')
    end_date = db.Column(db.Date, default=lambda: date.today() + timedelta(days=365), nullable=True, comment='合同结束日期（默认1年后）')

    # 合同状态
    status = db.Column(db.String(20), default='草稿', nullable=False, comment='合同状态：草稿/生效中/即将到期/已到期/已终止/已归档')

    # 经手人
    handler_user_id = db.Column(db.Integer, db.ForeignKey('users.id', ondelete='SET NULL'), nullable=True, comment='经手人用户ID')

    # 关联部门
    department_id = db.Column(db.Integer, db.ForeignKey('departments.id', ondelete='SET NULL'), nullable=True, comment='归属部门ID')

    # 备注
    remark = db.Column(db.Text, nullable=True, comment='备注信息')

    # 续签关系
    previous_contract_id = db.Column(db.Integer, db.ForeignKey('contracts.id', ondelete='SET NULL'), nullable=True, comment='上一份合同ID（续签关系链，指向原合同）')

    # 操作用户
    operator_user_id = db.Column(db.Integer, nullable=True, comment='操作用户ID')

    # 时间记录
    created_at = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='创建时间')
    updated_at = db.Column(db.DateTime, default=datetime.now, onupdate=datetime.now, nullable=False, comment='更新时间')

    # 关系定义
    attachments = db.relationship('ContractAttachment', backref='contract', lazy=True, cascade='all, delete-orphan')
    operation_records = db.relationship('ContractOperationRecord', backref='contract', lazy=True, cascade='all, delete-orphan')

    # 甲方乙方关系（需要指定foreign_keys避免歧义）
    party_a = db.relationship('Supplier', foreign_keys=[party_a_id], backref='contracts_as_party_a', lazy='select')
    party_b = db.relationship('Supplier', foreign_keys=[party_b_id], backref='contracts_as_party_b', lazy='select')

    # 经手人关系
    handler = db.relationship('User', foreign_keys=[handler_user_id], backref='handled_contracts', lazy='select')

    # 部门关系
    department = db.relationship('Department', foreign_keys=[department_id], backref='contracts', lazy='select')

    # 续签关系（自引用外键）
    previous_contract = db.relationship('Contract', remote_side=[id], foreign_keys=[previous_contract_id], backref='renewed_contracts', lazy='select')

    # 约束与索引
    __table_args__ = (
        db.CheckConstraint(
            "status IN ('草稿', '生效中', '即将到期', '已到期', '已终止', '已归档')",
            name='check_contract_status_valid'
        ),
        db.CheckConstraint(
            "end_date >= start_date",
            name='check_contract_date_range'
        ),
        db.Index('idx_contract_number', 'contract_number'),
        db.Index('idx_contract_name', 'contract_name'),
        db.Index('idx_contract_status', 'status'),
        db.Index('idx_contract_type', 'contract_type'),
        db.Index('idx_contract_party_a', 'party_a_id'),
        db.Index('idx_contract_party_b', 'party_b_id'),
        db.Index('idx_contract_start_date', 'start_date'),
        db.Index('idx_contract_end_date', 'end_date'),
        db.Index('idx_contract_signing_date', 'signing_date'),
        db.Index('idx_contract_handler', 'handler_user_id'),
        db.Index('idx_contract_department', 'department_id'),
        db.Index('idx_contract_previous', 'previous_contract_id'),
    )

    def __repr__(self):
        return f"<Contract {self.contract_number} - {self.contract_name}>"

    @property
    def display_status(self):
        """返回状态显示文本"""
        status_map = {
            '草稿': '草稿',
            '生效中': '生效中',
            '即将到期': '即将到期',
            '已到期': '已到期',
            '已终止': '已终止',
            '已归档': '已归档'
        }
        return status_map.get(self.status, self.status)

    @property
    def status_color(self):
        """返回状态对应的颜色标识（用于前端显示）"""
        color_map = {
            '草稿': 'gray',
            '生效中': 'green',
            '即将到期': 'yellow',
            '已到期': 'red',
            '已终止': 'red',
            '已归档': 'blue'
        }
        return color_map.get(self.status, 'gray')

    @property
    def days_until_expiry(self):
        """计算距到期日的天数，None表示无结束日期"""
        if self.end_date is None:
            return None
        delta = self.end_date - date.today()
        return delta.days

    @property
    def is_expiring_soon(self):
        """判断是否即将到期（30天内）"""
        days = self.days_until_expiry
        return days is not None and 0 < days <= 30

    @property
    def is_expired(self):
        """判断是否已到期"""
        days = self.days_until_expiry
        return days is not None and days <= 0

    @property
    def party_a_name(self):
        """返回甲方名称"""
        return self.party_a.name if self.party_a else '未指定'

    @property
    def party_b_name(self):
        """返回乙方名称"""
        return self.party_b.name if self.party_b else '未指定'

    @property
    def handler_name(self):
        """返回经手人姓名"""
        if self.handler_user_id:
            from models.user import User
            user = User.query.get(self.handler_user_id)
            return user.name if user else '未知'
        return '未指定'

    @property
    def department_name(self):
        """返回归属部门名称"""
        if self.department_id:
            from models.department import Department
            dept = Department.query.get(self.department_id)
            return dept.name if dept else '未知'
        return '未指定'

    @property
    def attachment_count(self):
        """返回附件数量"""
        return len(self.attachments) if self.attachments else 0

    @property
    def renewal_chain(self):
        """返回续签关系链（从当前合同向上追溯所有前序合同）
        返回列表按时间正序排列，最早的合同在前
        """
        chain = []
        current = self
        while current.previous_contract_id:
            prev = Contract.query.get(current.previous_contract_id)
            if prev:
                chain.insert(0, prev)
                current = prev
            else:
                break
        return chain

    @property
    def is_renewal(self):
        """判断当前合同是否为续签合同"""
        return self.previous_contract_id is not None

    @classmethod
    def create(cls, contract_name, contract_number=None, party_a_id=None, party_b_id=None,
               contract_type=None, contract_category=None, contract_amount=None,
               currency='CNY', tax_rate=None, signing_date=None, start_date=None, end_date=None,
               status='草稿', handler_user_id=None, department_id=None,
               previous_contract_id=None, remark=None, operator_user_id=None):
        """创建合同"""
        contract = cls(
            contract_name=contract_name,
            contract_number=contract_number,
            party_a_id=party_a_id,
            party_b_id=party_b_id,
            contract_type=contract_type,
            contract_category=contract_category,
            contract_amount=contract_amount,
            currency=currency,
            tax_rate=tax_rate,
            signing_date=signing_date or date.today(),
            start_date=start_date or date.today(),
            end_date=end_date or (date.today() + timedelta(days=365)),
            status=status,
            handler_user_id=handler_user_id,
            department_id=department_id,
            previous_contract_id=previous_contract_id,
            remark=remark,
            operator_user_id=operator_user_id
        )
        db.session.add(contract)
        db.session.commit()
        return contract

    @classmethod
    def is_number_exists(cls, contract_number, exclude_id=None):
        """检查合同编号是否已存在"""
        if not contract_number:
            return False
        query = cls.query.filter_by(contract_number=contract_number)
        if exclude_id:
            query = query.filter(cls.id != exclude_id)
        return query.first() is not None

    @classmethod
    def check_usage(cls, contract_id):
        """检查合同是否被使用，返回使用详情"""
        from models.contract.contract_attachment import ContractAttachment
        from models.contract.contract_operation_record import ContractOperationRecord

        attachment_count = ContractAttachment.query.filter_by(contract_id=contract_id).count()
        record_count = ContractOperationRecord.query.filter_by(contract_id=contract_id).count()

        return {
            'used': attachment_count > 0 or record_count > 0,
            'details': {
                'attachment_count': attachment_count,
                'record_count': record_count
            }
        }

    @classmethod
    def update_expiry_status(cls):
        """批量更新合同到期状态（可由定时任务调用）
        - 生效中的合同，如果已过期 → 更新为'已到期'
        - 生效中的合同，如果30天内到期 → 更新为'即将到期'
        """
        today = date.today()
        warning_date = today + timedelta(days=30)

        # 更新已到期
        expired_contracts = cls.query.filter(
            cls.status == '生效中',
            cls.end_date < today
        ).all()
        for c in expired_contracts:
            c.status = '已到期'

        # 更新即将到期
        expiring_contracts = cls.query.filter(
            cls.status == '生效中',
            cls.end_date >= today,
            cls.end_date <= warning_date
        ).all()
        for c in expiring_contracts:
            c.status = '即将到期'

        db.session.commit()
        return len(expired_contracts), len(expiring_contracts)

    @classmethod
    def get_expiring_contracts(cls, days=30):
        """获取即将到期的合同列表"""
        today = date.today()
        warning_date = today + timedelta(days=days)
        return cls.query.filter(
            cls.end_date >= today,
            cls.end_date <= warning_date,
            cls.status.in_(['生效中', '即将到期'])
        ).order_by(cls.end_date).all()

    @classmethod
    def get_expired_contracts(cls):
        """获取已到期但未处理的合同列表"""
        today = date.today()
        return cls.query.filter(
            cls.end_date < today,
            cls.status.in_(['生效中', '即将到期'])
        ).order_by(cls.end_date).all()
```

```python
from datetime import datetime
from utils.db import db


class ContractOperationRecord(db.Model):
    """合同操作记录表 - 记录所有创建/编辑/状态变更/附件操作的详细变更"""
    __tablename__ = 'contract_operation_records'

    id = db.Column(db.Integer, primary_key=True)
    contract_id = db.Column(db.Integer, db.ForeignKey('contracts.id', ondelete='CASCADE'), nullable=False, comment='关联合同ID')
    operation_type = db.Column(db.String(20), nullable=False, comment='操作类型：add/edit/delete/status_change/upload_attachment/delete_attachment')
    operator_id = db.Column(db.Integer, nullable=True, comment='操作人ID')
    operator_name = db.Column(db.String(50), nullable=True, comment='操作人姓名')
    operation_time = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='操作时间')

    # 变更详情（JSON格式，记录变更前后值）
    change_detail = db.Column(db.Text, nullable=True, comment='变更详情（JSON格式）')
    # 示例: {"field": "status", "old_value": "草稿", "new_value": "生效中"}
    # 编辑操作: [{"field": "contract_name", "old": "旧名称", "new": "新名称"}, ...]
    # 附件操作: {"filename": "合同扫描件.pdf", "action": "upload"}

    # 操作摘要（便于快速查看）
    summary = db.Column(db.String(500), nullable=True, comment='操作摘要')

    # 索引
    __table_args__ = (
        db.Index('idx_cor_contract_id', 'contract_id'),
        db.Index('idx_cor_operation_type', 'operation_type'),
        db.Index('idx_cor_operation_time', 'operation_time'),
        db.Index('idx_cor_contract_time', 'contract_id', 'operation_time'),
    )

    def __repr__(self):
        return f"<ContractOperationRecord contract={self.contract_id} type={self.operation_type}>"

    @classmethod
    def create_record(cls, contract_id, operation_type, operator_id=None,
                      operator_name=None, change_detail=None, summary=None):
        """创建操作记录"""
        import json
        record = cls(
            contract_id=contract_id,
            operation_type=operation_type,
            operator_id=operator_id,
            operator_name=operator_name,
            change_detail=json.dumps(change_detail, ensure_ascii=False) if isinstance(change_detail, (dict, list)) else change_detail,
            summary=summary
        )
        db.session.add(record)
        db.session.commit()
        return record
```

## 四、附件上传方案设计

### 4.1 附件管理工具类 - ContractAttachmentManager

文件: `utils/contract_attachment.py`

参照现有 `AssetPhotoManager` 的设计模式，创建合同附件管理工具类：

```python
import os
import random
import mimetypes
from flask import current_app
from datetime import datetime


# 支持的文件格式分类
ALLOWED_IMAGE_EXTENSIONS = {'png', 'jpg', 'jpeg', 'gif', 'bmp', 'webp', 'svg'}
ALLOWED_VIDEO_EXTENSIONS = {'mp4', 'avi', 'mov', 'wmv', 'flv', 'mkv', 'webm'}
ALLOWED_DOCUMENT_EXTENSIONS = {'pdf', 'doc', 'docx', 'xls', 'xlsx', 'ppt', 'pptx', 'txt', 'csv', 'ofd'}
ALLOWED_COMPRESSED_EXTENSIONS = {'zip', 'rar', '7z', 'tar', 'gz'}

# 合同附件允许的所有扩展名
ALLOWED_EXTENSIONS = ALLOWED_IMAGE_EXTENSIONS | ALLOWED_VIDEO_EXTENSIONS | ALLOWED_DOCUMENT_EXTENSIONS | ALLOWED_COMPRESSED_EXTENSIONS

class ContractAttachmentManager:
    """合同附件管理工具类，处理合同附件的上传、存储和访问"""

    @staticmethod
    def get_media_root_dir():
        """获取合同附件的根目录，确保正确目录存在
        根据不同环境(Docker、Windows打包、开发环境)返回正确的数据存储路径
        """
        import sys

        # 检查是否是Docker环境
        if os.environ.get('DOCKER_ENV') == 'true':
            media_root = '/data/contract_attachments'
        # 检查是否是PyInstaller打包环境
        elif getattr(sys, 'frozen', False):
            app_dir = os.path.dirname(os.path.abspath(sys.executable))
            media_root = os.path.join(app_dir, 'data', 'contract_attachments')
        else:
            app_root = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
            media_root = os.path.join(app_root, 'data', 'contract_attachments')

        os.makedirs(media_root, exist_ok=True)
        return media_root

    @staticmethod
    def ensure_contract_directory_exists(contract_id):
        """确保特定合同的附件目录存在
        目录结构: data/contract_attachments/{contract_id}/
        """
        media_root = ContractAttachmentManager.get_media_root_dir()
        contract_dir = os.path.join(media_root, str(contract_id))
        os.makedirs(contract_dir, exist_ok=True)
        return contract_dir

    @staticmethod
    def is_allowed_file(filename):
        """检查文件扩展名是否允许"""
        if '.' not in filename:
            return False
        ext = filename.rsplit('.', 1)[1].lower()
        return ext in ALLOWED_EXTENSIONS

    @staticmethod
    def get_file_type(filename):
        """根据文件扩展名判断文件类型"""
        if '.' not in filename:
            return 'other'
        ext = filename.rsplit('.', 1)[1].lower()
        if ext in ALLOWED_IMAGE_EXTENSIONS:
            return 'image'
        elif ext in ALLOWED_VIDEO_EXTENSIONS:
            return 'video'
        elif ext in ALLOWED_DOCUMENT_EXTENSIONS:
            return 'document'
        elif ext in ALLOWED_COMPRESSED_EXTENSIONS:
            return 'compressed'
        else:
            return 'other'

    @staticmethod
    def upload_file(contract_id, file, description=None, uploader_id=None, uploader_name=None):
        """上传合同附件

        Args:
            contract_id: 合同ID
            file: Flask文件对象
            description: 附件描述
            uploader_id: 上传人ID
            uploader_name: 上传人姓名

        Returns:
            ContractAttachment: 附件记录对象，失败返回None
        """
        from models.contract.contract_attachment import ContractAttachment

        original_filename = file.filename or ''

        # 校验文件类型
        if not ContractAttachmentManager.is_allowed_file(original_filename):
            return None

        # 获取文件大小
        file.seek(0, 2)  # 移到文件末尾
        file_size = file.tell()
        file.seek(0)  # 重置指针

        # 确保目录存在
        contract_dir = ContractAttachmentManager.ensure_contract_directory_exists(contract_id)

        # 生成唯一文件名
        ext = ''
        if '.' in original_filename:
            ext = '.' + original_filename.rsplit('.', 1)[1].lower()
        timestamp = datetime.now().strftime('%Y%m%d%H%M%S')
        random_hex = '%04x' % random.randint(0, 0xFFFF)
        saved_filename = f"{timestamp}_{random_hex}{ext}"

        # 保存文件
        file_path = os.path.join(contract_dir, saved_filename)
        file.save(file_path)

        # 获取文件类型
        file_type = ContractAttachmentManager.get_file_type(original_filename)
        file_extension = ext.lstrip('.') if ext else None

        # 相对路径（用于数据库存储）
        relative_path = os.path.join(str(contract_id), saved_filename)

        # 创建数据库记录
        attachment = ContractAttachment.create(
            contract_id=contract_id,
            original_filename=original_filename,
            saved_filename=saved_filename,
            file_path=relative_path,
            file_size=file_size,
            file_type=file_type,
            file_extension=file_extension,
            description=description,
            uploader_id=uploader_id,
            uploader_name=uploader_name
        )

        return attachment

    @staticmethod
    def delete_file(attachment_id):
        """删除合同附件（同时删除文件和数据库记录）"""
        from models.contract.contract_attachment import ContractAttachment

        attachment = ContractAttachment.query.get(attachment_id)
        if not attachment:
            return False

        # 删除物理文件
        media_root = ContractAttachmentManager.get_media_root_dir()
        file_path = os.path.join(media_root, attachment.file_path)
        if os.path.exists(file_path):
            os.remove(file_path)

        # 删除数据库记录
        db.session.delete(attachment)
        db.session.commit()
        return True

    @staticmethod
    def get_contract_attachments(contract_id):
        """获取合同的所有附件列表"""
        from models.contract.contract_attachment import ContractAttachment
        return ContractAttachment.query.filter_by(contract_id=contract_id).order_by(ContractAttachment.created_at.desc()).all()

    @staticmethod
    def get_file_full_path(attachment):
        """获取附件的完整文件路径"""
        media_root = ContractAttachmentManager.get_media_root_dir()
        return os.path.join(media_root, attachment.file_path)

    @staticmethod
    def delete_contract_directory(contract_id):
        """删除合同的整个附件目录（合同删除时调用）"""
        import shutil
        media_root = ContractAttachmentManager.get_media_root_dir()
        contract_dir = os.path.join(media_root, str(contract_id))
        if os.path.exists(contract_dir):
            shutil.rmtree(contract_dir)
```

### 4.2 附件上传设计要点

1. **存储路径**：`data/contract_attachments/{contract_id}/{timestamp}_{random}{ext}`
   - 每个合同一个独立子目录，便于管理和清理
   - 文件名使用时间戳+随机数，避免中文文件名问题
   - 数据库存储相对路径，确保跨环境兼容

2. **文件类型支持**：
   - 图片：png, jpg, jpeg, gif, bmp, webp, svg
   - 视频：mp4, avi, mov, wmv, flv, mkv, webm
   - 文档：pdf, doc, docx, xls, xlsx, ppt, pptx, txt, csv, ofd
   - 压缩包：zip, rar, 7z, tar, gz

3. **安全限制**：
   - 仅允许白名单内的文件扩展名
   - 文件名重命名策略：时间戳+随机数+保留原始扩展名

4. **上传时机**：
   - 合同创建后（合同已有ID）才能上传附件
   - 支持在合同详情页/编辑页上传附件
   - 支持拖拽上传和按钮上传两种方式

5. **附件管理功能**：
   - 查看附件列表（显示文件名、大小、类型、上传时间、上传人）
   - 下载附件（使用原始文件名下载）
   - 删除附件（同时删除文件和数据库记录）
   - 附件描述（可标注"合同正文"、"补充协议"等）

**新增合同操作流程**：
1. 接收表单数据（合同名称、甲乙双方、金额、税率、日期等）
2. 合同编号：用户可自定义，留空则自动生成（HT+年月+4位序号）
3. 税率处理：若用户未手动输入税率且选择了供应商，从供应商获取税率自动填充
4. 续签处理：若表单包含 `previous_contract_id`，设置续签关系，并从原合同复制基本信息
5. 签订日期默认当天，开始日期默认当天，结束日期默认1年后
6. 创建合同记录
7. 记录操作记录（operation_type='add'，续签时记录续签来源信息）
8. 记录操作日志（log_operation）

**编辑合同操作流程**：
1. 接收表单数据
2. 对比新旧值，记录变更详情（change_detail）
3. 更新合同记录
4. 记录操作记录（operation_type='edit'）
5. 记录操作日志

**状态变更操作流程**：
1. 接收新状态值
2. 校验状态流转合法性（草稿→生效中、生效中→已终止/已归档等）
3. 更新状态
4. 记录操作记录（operation_type='status_change'，记录前后状态）
5. 记录操作日志

**附件上传操作流程**：
1. 校验文件类型
2. 调用 `ContractAttachmentManager.upload_file()` 保存文件
3. 创建 `ContractAttachment` 数据库记录
4. 记录操作记录（operation_type='upload_attachment'）
5. 记录操作日志

**续签操作流程**：
1. 用户在列表页点击"续签"按钮（仅"已到期"或"即将到期"合同显示此按钮）
2. 跳转到新增合同页面，自动填充原合同信息：
   - 复制字段：合同名称（追加"（续签）"后缀）、甲乙方、合同金额、税率、合同类型、合同分类、经手人、归属部门
   - 设置 `previous_contract_id` 为原合同ID
   - 日期默认值：签订日期为当天，开始日期为原合同结束日期次日，结束日期为开始日期+原合同期限天数
3. 用户可修改任何自动填充的字段（包括税率）
4. 提交创建新合同记录
5. 记录操作记录（operation_type='add'，change_detail中记录续签来源）

## 十一、合同状态流转设计

```
草稿 ──→ 生效中 ──→ 即将到期 ──→ 已到期
  │         │                         │
  │         ├──→ 已终止               ├──→ 已归档
  │         │                         │
  │         └──→ 已归档               ├──→ 已终止
  │                                   │
  └──────────────────────────────────→ 已终止
                                      │
                            已到期/即将到期 ──→ 续签（创建新合同）

注：
- "即将到期"和"已到期"状态由系统自动更新（通过 update_expiry_status 方法）
- 也可手动变更状态
- 已终止和已归档为终态，不可回退
- 草稿可直接变为已终止（取消草稿）
- 续签操作不改变原合同状态，而是创建新合同并通过 previous_contract_id 关联原合同
```

**合法状态流转规则**：

| 当前状态 | 可变更到 |
|---------|---------|
| 草稿 | 生效中、已终止 |
| 生效中 | 即将到期、已到期、已终止、已归档 |
| 即将到期 | 生效中（续签）、已到期、已终止、已归档 |
| 已到期 | 生效中（续签）、已终止、已归档 |
| 已终止 | （终态，不可变更） |
| 已归档 | （终态，不可变更） |

**续签状态流转说明**：

- "即将到期"和"已到期"状态可流转到"生效中"，此流转代表续签场景
- 续签时**不修改原合同状态**，而是创建一份新合同，新合同的 `previous_contract_id` 指向原合同
- 续签创建的新合同初始状态为"草稿"，需手动激活为"生效中"
- 续签关系链通过 `previous_contract_id` 自引用外键实现，支持多级续签追溯
- 续签操作入口：列表页"已到期"/"即将到期"合同的操作栏中显示"续签"按钮

## 十三、续签关系链设计

### 13.1 数据模型

续签关系通过合同主表的自引用外键 `previous_contract_id` 实现：

```python
# 合同模型中的续签字段
previous_contract_id = db.Column(db.Integer, db.ForeignKey('contracts.id', ondelete='SET NULL'), nullable=True, comment='上一份合同ID（续签关系链，指向原合同）')

# 自引用关系
previous_contract = db.relationship('Contract', remote_side=[id], foreign_keys=[previous_contract_id], backref='renewed_contracts', lazy='select')
```

**设计要点**：
- `previous_contract_id` 为可空字段，非续签合同此字段为空
- 使用 `ondelete='SET NULL'`，原合同删除时不级联删除续签合同，仅断开关联
- `backref='renewed_contracts'` 提供反向查询，可获取某合同的所有续签后续合同
- 索引 `idx_contract_previous` 加速续签关系查询

### 13.2 续签关系链查询

**向上追溯（查询完整续签链）**：

```python
@property
def renewal_chain(self):
    """返回续签关系链（从最早原合同到当前合同，按时间正序）"""
    chain = []
    current = self
    while current.previous_contract_id:
        prev = Contract.query.get(current.previous_contract_id)
        if prev:
            chain.insert(0, prev)
            current = prev
        else:
            break
    return chain
```

**向下查询（查询后续续签合同）**：

```python
# 通过 backref 直接访问
contract.renewed_contracts  # 返回当前合同的所有直接续签合同列表
```

**API查询接口**：

```
GET /api/contracts/<int:id>/renewal-chain
```

返回指定合同的完整续签关系链，包括所有前序合同和后续续签合同。

### 13.3 续签关系链展示方案

**详情页展示**：
- 续签关系链以时间线形式展示，每个节点包含：合同编号、合同名称、签订日期、状态标签
- 当前合同节点高亮，前序/后续合同节点可点击跳转

### 13.4 税率自动填充设计

**数据来源**：
- 供应商表 `suppliers.tax_rate` 字段存储供应商默认税率
- 合同表 `contracts.tax_rate` 字段存储合同实际税率

**自动填充规则**：
1. 新建合同时，选择甲方供应商后，前端调用 `GET /api/contracts/suppliers/<int:id>/tax-rate` 获取税率
2. 若甲方有税率则自动填入；若甲方无税率，尝试从乙方获取
3. 自动填充后字段可编辑，用户可手动覆盖
4. 自动填充时显示"已从供应商获取"提示标签

**续签场景税率处理**：
- 续签时优先从原合同复制税率（保持业务连续性）
- 若原合同无税率，再从供应商获取
- 用户始终可手动修改

**前端交互实现**：
```javascript
// 供应商选择变更时触发税率自动填充
async function onSupplierChange(supplierId, partyType) {
    const response = await fetch(`/api/contracts/suppliers/${supplierId}/tax-rate`);
    const data = await response.json();
    if (data.tax_rate !== null && !taxRateManuallyEdited) {
        document.getElementById('tax_rate').value = data.tax_rate;
        showAutoFillBadge(partyType);  // 显示"已从供应商获取"提示
    }
}

// 续签时从原合同复制税率
function onRenewContract(sourceContract) {
    if (sourceContract.tax_rate) {
        document.getElementById('tax_rate').value = sourceContract.tax_rate;
        showAutoFillBadge('renew');  // 显示"已从原合同复制"提示
    }
}
```
