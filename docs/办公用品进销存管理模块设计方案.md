# 办公用品进销存管理模块设计方案

## 一、模块概述

基于现有宿舍管理系统架构，新增办公用品进销存管理模块，实现办公用品从采购入库、领用出库、库存盘点到基础资料管理的全流程管理。模块包含四个子模块：

1. **供应商管理**：供应商增删改查、供应商操作记录、经手人关联用户、供应商状态（启用/停用）
2. **基础资料管理**：办公用品物品属性管理、存放位置管理、库存明细管理（按物品+存放位置维度）
3. **进销存管理**：入库（采购入库/其它入库）、出库（正常领用/其他出库）、盘点、进出库记录
4. **进出库记录**：自动记录所有入库、出库、盘点调整操作，关联操作人、领用人、部门、存放位置

**核心定位**：办公用品进销存管理模块是固定资产管理模块的补充，专注于低值易耗品和日常办公用品的采购、领用、库存管理，与现有部门管理、用户管理模块深度集成，实现按部门、按人员追溯的办公用品消耗管理。

**库存双维度设计**：
- `SupplyItem.current_stock`：物品总库存（所有存放位置汇总），用于快速查询物品总库存
- `SupplyStockDetail`：按物品+存放位置维度的库存明细，用于精确追踪每个位置的库存数量
- 入库/出库/盘点时同时更新两个维度，确保数据一致性

## 二、架构设计原则

严格遵循项目现有架构模式：

### 2.1 Blueprint四层分层架构

| 层次 | 文件后缀 | URL前缀 | 蓝图变量命名 | 职责 |
|------|---------|---------|-------------|------|
| 主蓝图 | `module.py` | `/module` | `module_bp` | 列表页+表单页(GET) |
| 操作蓝图 | `module_operations.py` | 注册到主蓝图 | 无独立蓝图 | CRUD操作(POST) |
| API蓝图 | `module_api.py` | `/api/modules` | `module_api_bp` | JSON响应 |
| 导入导出蓝图 | `module_import_export.py` | `/module/import-export` | `module_import_export_bp` | Excel导入导出 |

**关键模式**：操作蓝图不创建独立Blueprint对象，路由直接注册到主蓝图上。操作蓝图文件顶部导入主蓝图：
```python
from .module import module_bp
@module_bp.route('/operations/add', methods=['POST'])
```
主蓝图文件底部触发操作路由注册：
```python
from . import module_operations
```

### 2.2 模型设计模式

- **命名**：蛇形命名法，一个模型类一个文件
- **表名**：复数形式（如 `suppliers`, `supply_items`, `supply_stock_details`）
- **主键**：`id = db.Column(db.Integer, primary_key=True)`
- **时间戳**：`created_at` + `updated_at`（`default=datetime.now`, `onupdate=datetime.now`）
- **操作人**：`operator_user_id = db.Column(db.Integer, nullable=True)`
- **字段注释**：每个 `db.Column` 必带 `comment='中文说明'`
- **约束命名**：`uq_表名_字段名`（唯一）/ `check_约束描述`（检查）
- **索引命名**：`idx_表缩写_字段名`
- **关系定义**：`db.relationship` + `backref` + `cascade='all, delete-orphan'`
- **外键**：`db.ForeignKey('table.id', ondelete='CASCADE')`
- **类方法**：`create(cls, ...)`, `get_all_names()`, `is_name_exists()`, `check_usage()`
- **属性方法**：`@property display_number` 等

### 2.3 子文件夹组织

由于项目根目录下模型和蓝图文件数量较多，本模块采用子文件夹组织：

**模型子文件夹**: `models/supply/`
- 创建 `models/supply/__init__.py` 作为包初始化文件，导出所有模型类
- 所有12个模型文件放在 `models/supply/` 子文件夹内
- `models/__init__.py` 新增：`from .supply import Supplier, SupplierOperationRecord, SupplyItem, StorageLocation, SupplyStockDetail, StockIn, StockInDetail, StockOut, StockOutDetail, SupplyInventory, SupplyInventoryDetail, SupplyStockRecord`

**蓝图子文件夹**: `blueprints/supply/`
- 创建 `blueprints/supply/__init__.py` 作为包初始化文件，导出所有蓝图变量
- 所有蓝图文件放在 `blueprints/supply/` 子文件夹内
- 操作蓝图导入主蓝图时使用相对导入：`from .supplier import supplier_bp`
- `blueprints/__init__.py` 新增：`from .supply import supplier_bp, supplier_api_bp, supplier_import_export_bp, ...`

### 2.4 编号规则

| 单据类型 | 编号前缀 | 格式 | 示例 |
|---------|---------|------|------|
| 物品编号 | YP | YP+年月+4位序号 | YP2026080001 |
| 入库单号 | RK | RK+年月+4位序号 | RK2026080001 |
| 出库单号 | CK | CK+年月+4位序号 | CK2026080001 |
| 盘点单号 | PD | PD+年月+4位序号 | PD2026080001 |

### 2.5 其他原则

- **配置驱动**: 功能开关从`SystemConfig`读取，入库类型、出库类型、物品分类等从系统配置获取
- **操作日志**: 同时调用`log_operation`写入`OperationLog`，并写入专用操作记录表（`SupplierOperationRecord`）记录变更详情
- **权限控制**: `admin_required`装饰器 + `login_required`认证，仅管理员可访问
- **删除验证**: 删除前检查是否被引用，被引用时返回使用详情并禁止删除
- **前端技术栈**: TailwindCSS + FontAwesome + Jinja2模板
- **导入导出模式**: 参照`fixed_asset_import_export.py`，使用pandas + openpyxl实现Excel导入导出
- **主从表模式**: 入库单(主表+明细)、出库单(主表+明细)、盘点单(主表+明细)均采用主从表设计，`cascade='all, delete-orphan'`级联删除
- **库存联动**: 入库/出库/盘点操作同时更新`SupplyStockDetail`（按位置增减）和`SupplyItem.current_stock`（汇总），并写入`SupplyStockRecord`

## 三、数据模型设计

### 3.1 供应商表 - Supplier

文件: `models/supply/supplier.py`

```python
from datetime import datetime
from utils.db import db

class Supplier(db.Model):
    """供应商表"""
    __tablename__ = 'suppliers'

    # 核心字段
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(200), nullable=False, comment='供应商名称')
    contact_person = db.Column(db.String(100), nullable=True, comment='联系人')
    contact_phone = db.Column(db.String(50), nullable=True, comment='联系电话')
    email = db.Column(db.String(200), nullable=True, comment='邮箱')
    address = db.Column(db.String(500), nullable=True, comment='地址')

    # 状态与关联
    status = db.Column(db.String(20), default='启用', nullable=False, comment='状态：启用/停用')
    handler_user_id = db.Column(db.Integer, db.ForeignKey('users.id', ondelete='SET NULL'), nullable=True, comment='经手人用户ID')
    company = db.Column(db.String(100), nullable=True, comment='所属公司')

    # 备注
    remark = db.Column(db.Text, nullable=True, comment='备注信息')

    # 操作用户
    operator_user_id = db.Column(db.Integer, nullable=True, comment='操作用户ID')

    # 时间记录
    created_at = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='创建时间')
    updated_at = db.Column(db.DateTime, default=datetime.now, onupdate=datetime.now, nullable=False, comment='更新时间')

    # 关系定义
    operation_records = db.relationship('SupplierOperationRecord', backref='supplier', lazy=True, cascade='all, delete-orphan')
    supply_items = db.relationship('SupplyItem', backref='supplier', lazy=True)

    # 约束与索引
    __table_args__ = (
        db.UniqueConstraint('name', 'company', name='uq_supplier_name_company', comment='同公司下供应商名称唯一'),
        db.CheckConstraint(
            "status IN ('启用', '停用')",
            name='check_supplier_status_valid'
        ),
        db.Index('idx_supplier_name', 'name'),
        db.Index('idx_supplier_company', 'company'),
        db.Index('idx_supplier_status', 'status'),
        db.Index('idx_supplier_handler', 'handler_user_id'),
    )

    def __repr__(self):
        return f"<Supplier {self.name} ({self.company})>"

    @property
    def display_status(self):
        """返回状态显示文本"""
        status_map = {'启用': '启用', '停用': '停用'}
        return status_map.get(self.status, self.status)

    @property
    def handler_name(self):
        """返回经手人姓名"""
        if self.handler_user_id:
            from models.user import User
            user = User.query.get(self.handler_user_id)
            return user.name if user else '未知'
        return '未指定'

    @classmethod
    def create(cls, name, contact_person=None, contact_phone=None,
               email=None, address=None, status='启用', handler_user_id=None,
               company=None, remark=None, operator_user_id=None):
        """创建供应商"""
        supplier = cls(
            name=name,
            contact_person=contact_person,
            contact_phone=contact_phone,
            email=email,
            address=address,
            status=status,
            handler_user_id=handler_user_id,
            company=company,
            remark=remark,
            operator_user_id=operator_user_id
        )
        db.session.add(supplier)
        db.session.commit()
        return supplier

    @classmethod
    def is_name_exists(cls, name, company=None, exclude_id=None):
        """检查供应商名称是否已存在（同公司下名称唯一）"""
        query = cls.query.filter_by(name=name)
        if company:
            query = query.filter(db.or_(cls.company == company, cls.company.is_(None)))
        else:
            query = query.filter(cls.company.is_(None))
        if exclude_id:
            query = query.filter(cls.id != exclude_id)
        return query.first() is not None

    @classmethod
    def check_usage(cls, supplier_id):
        """
        检查供应商是否被使用，返回使用详情
        返回: {'used': bool, 'details': dict}
        """
        from models.supply.supply_item import SupplyItem

        # 检查 SupplyItem.supplier_id
        item_count = SupplyItem.query.filter_by(supplier_id=supplier_id).count()

        used = item_count > 0

        return {
            'used': used,
            'details': {
                'item_count': item_count
            }
        }

    @classmethod
    def get_active_suppliers(cls, company=None):
        """获取所有启用的供应商列表"""
        query = cls.query.filter_by(status='启用')
        if company:
            query = query.filter(db.or_(cls.company == company, cls.company.is_(None)))
        return query.order_by(cls.name).all()

    @classmethod
    def get_by_company(cls, company):
        """根据公司名称获取供应商列表"""
        return cls.query.filter_by(company=company).order_by(cls.name).all()

    @classmethod
    def get_all_names(cls):
        """获取所有供应商名称列表"""
        suppliers = cls.query.order_by(cls.name).all()
        return [s.name for s in suppliers]
```

**设计说明**：
- `name` 与 `company` 组成联合唯一约束 `uq_supplier_name_company`，允许不同公司下存在同名供应商
- `handler_user_id` 外键关联 `users` 表，`ondelete='SET NULL'`，用户删除时经手人字段置空
- `status` 字段使用检查约束限制为"启用"或"停用"
- `operation_records` 关系使用 `cascade='all, delete-orphan'`，删除供应商时级联删除操作记录
- `supply_items` 关系不使用级联删除，删除供应商时需先检查是否被物品引用
- `check_usage()` 类方法用于删除前验证，检查是否被 `SupplyItem` 引用

### 3.2 供应商操作记录表 - SupplierOperationRecord

文件: `models/supply/supplier_operation_record.py`

```python
from datetime import datetime
from utils.db import db

class SupplierOperationRecord(db.Model):
    """供应商操作记录表 - 记录所有增加/修改/状态变更操作的详细变更"""
    __tablename__ = 'supplier_operation_records'

    id = db.Column(db.Integer, primary_key=True)
    supplier_id = db.Column(db.Integer, db.ForeignKey('suppliers.id', ondelete='CASCADE'), nullable=False, comment='关联供应商ID')
    operation_type = db.Column(db.String(20), nullable=False, comment='操作类型：add/edit/delete/enable/disable')
    operator_id = db.Column(db.Integer, nullable=True, comment='操作人ID')
    operator_name = db.Column(db.String(50), nullable=True, comment='操作人姓名')
    operation_time = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='操作时间')

    # 变更详情（JSON格式，记录变更前后值）
    change_detail = db.Column(db.Text, nullable=True, comment='变更详情（JSON格式）')
    # 示例: {"field": "status", "old_value": "停用", "new_value": "启用"}
    # 编辑操作: [{"field": "name", "old": "供应商A", "new": "供应商B"}, {"field": "contact_person", "old": "张三", "new": "李四"}]

    # 操作摘要（便于快速查看）
    summary = db.Column(db.String(500), nullable=True, comment='操作摘要')

    # 索引
    __table_args__ = (
        db.Index('idx_sor_supplier_id', 'supplier_id'),
        db.Index('idx_sor_operation_type', 'operation_type'),
        db.Index('idx_sor_operation_time', 'operation_time'),
        db.Index('idx_sor_supplier_time', 'supplier_id', 'operation_time'),
    )

    def __repr__(self):
        return f"<SupplierOperationRecord supplier={self.supplier_id} type={self.operation_type}>"

    @classmethod
    def create_record(cls, supplier_id, operation_type, operator_id=None,
                      operator_name=None, change_detail=None, summary=None):
        """创建操作记录"""
        import json
        record = cls(
            supplier_id=supplier_id,
            operation_type=operation_type,
            operator_id=operator_id,
            operator_name=operator_name,
            change_detail=json.dumps(change_detail, ensure_ascii=False) if isinstance(change_detail, dict) else change_detail,
            summary=summary
        )
        db.session.add(record)
        db.session.commit()
        return record
```

**设计说明**：
- 参照 `AssetOperationRecord` 模式，使用 `change_detail` JSON字段记录变更详情
- `operation_type` 支持：add（新增）、edit（编辑）、delete（删除）、enable（启用）、disable（停用）
- `supplier_id` 外键使用 `ondelete='CASCADE'`，删除供应商时级联删除操作记录
- `create_record()` 类方法封装记录创建逻辑，自动处理JSON序列化

### 3.3 办公用品基础资料表 - SupplyItem

文件: `models/supply/supply_item.py`

```python
from datetime import datetime
from utils.db import db

class SupplyItem(db.Model):
    """办公用品基础资料表"""
    __tablename__ = 'supply_items'

    # 核心字段
    id = db.Column(db.Integer, primary_key=True)
    item_number = db.Column(db.String(50), unique=True, nullable=False, comment='物品编号（自动生成，如YP2026080001）')
    name = db.Column(db.String(200), nullable=False, comment='物品名称')
    category = db.Column(db.String(100), nullable=True, comment='物品分类（从系统配置获取）')
    specification = db.Column(db.String(200), nullable=True, comment='规格型号')
    unit = db.Column(db.String(20), nullable=True, comment='计量单位（个/盒/箱/包/瓶/支/本/套等）')

    # 供应商关联
    supplier_id = db.Column(db.Integer, db.ForeignKey('suppliers.id', ondelete='SET NULL'), nullable=True, comment='默认供应商ID')

    # 价格信息
    unit_price = db.Column(db.Numeric(10, 2), default=0, nullable=False, comment='单价')
    reference_price = db.Column(db.Numeric(10, 2), nullable=True, comment='参考价格')

    # 库存信息（汇总维度，由SupplyStockDetail聚合计算）
    current_stock = db.Column(db.Integer, default=0, nullable=False, comment='当前总库存数量（所有存放位置汇总）')
    min_stock = db.Column(db.Integer, default=0, nullable=False, comment='最低库存预警数量')
    max_stock = db.Column(db.Integer, nullable=True, comment='最高库存数量')

    # 状态与关联
    status = db.Column(db.String(20), default='启用', nullable=False, comment='状态：启用/停用')
    company = db.Column(db.String(100), nullable=True, comment='所属公司')

    # 备注
    remark = db.Column(db.Text, nullable=True, comment='备注信息')

    # 操作用户
    operator_user_id = db.Column(db.Integer, nullable=True, comment='操作用户ID')

    # 时间记录
    created_at = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='创建时间')
    updated_at = db.Column(db.DateTime, default=datetime.now, onupdate=datetime.now, nullable=False, comment='更新时间')

    # 关系定义
    stock_details = db.relationship('SupplyStockDetail', backref='supply_item', lazy=True, cascade='all, delete-orphan')
    stock_in_details = db.relationship('StockInDetail', backref='supply_item', lazy=True)
    stock_out_details = db.relationship('StockOutDetail', backref='supply_item', lazy=True)
    inventory_details = db.relationship('SupplyInventoryDetail', backref='supply_item', lazy=True)
    stock_records = db.relationship('SupplyStockRecord', backref='supply_item', lazy=True)

    # 约束与索引
    __table_args__ = (
        db.UniqueConstraint('item_number', name='uq_supply_item_item_number', comment='物品编号唯一'),
        db.CheckConstraint(
            "status IN ('启用', '停用')",
            name='check_supply_item_status_valid'
        ),
        db.CheckConstraint(
            "current_stock >= 0",
            name='check_supply_item_stock_non_negative'
        ),
        db.CheckConstraint(
            "min_stock >= 0",
            name='check_supply_item_min_stock_non_negative'
        ),
        db.Index('idx_si_name', 'name'),
        db.Index('idx_si_category', 'category'),
        db.Index('idx_si_supplier', 'supplier_id'),
        db.Index('idx_si_status', 'status'),
        db.Index('idx_si_company', 'company'),
        db.Index('idx_si_item_number', 'item_number'),
    )

    def __repr__(self):
        return f"<SupplyItem {self.item_number} - {self.name}>"

    @property
    def display_number(self):
        """返回显示编号"""
        return self.item_number or f'YP-{self.id:06d}'

    @property
    def display_status(self):
        """返回状态显示文本"""
        return self.status

    @property
    def is_low_stock(self):
        """是否低于最低库存"""
        return self.current_stock <= self.min_stock

    @property
    def supplier_name(self):
        """返回供应商名称"""
        if self.supplier_id:
            from models.supply.supplier import Supplier
            supplier = Supplier.query.get(self.supplier_id)
            return supplier.name if supplier else '未知'
        return '未指定'

    @classmethod
    def create(cls, name, category=None, specification=None, unit=None,
               supplier_id=None, unit_price=0, reference_price=None,
               min_stock=0, max_stock=None, status='启用', company=None,
               remark=None, operator_user_id=None):
        """创建物品（自动生成编号）"""
        item = cls(
            name=name,
            category=category,
            specification=specification,
            unit=unit,
            supplier_id=supplier_id,
            unit_price=unit_price,
            reference_price=reference_price,
            min_stock=min_stock,
            max_stock=max_stock,
            status=status,
            company=company,
            remark=remark,
            operator_user_id=operator_user_id
        )
        db.session.add(item)
        db.session.flush()  # 获取id后生成编号
        item.item_number = cls.generate_item_number()
        db.session.commit()
        return item

    @classmethod
    def generate_item_number(cls):
        """生成物品编号：YP+年月+4位序号"""
        from datetime import datetime
        prefix = 'YP' + datetime.now().strftime('%Y%m')
        last_item = cls.query.filter(
            cls.item_number.like(prefix + '%')
        ).order_by(cls.item_number.desc()).first()

        if last_item and last_item.item_number.startswith(prefix):
            seq = int(last_item.item_number[len(prefix):]) + 1
        else:
            seq = 1
        return f'{prefix}{seq:04d}'

    @classmethod
    def is_name_exists(cls, name, exclude_id=None, company=None):
        """检查物品名称是否已存在"""
        query = cls.query.filter_by(name=name)
        if company:
            query = query.filter(db.or_(cls.company == company, cls.company.is_(None)))
        if exclude_id:
            query = query.filter(cls.id != exclude_id)
        return query.first() is not None

    @classmethod
    def check_usage(cls, item_id):
        """
        检查物品是否被使用，返回使用详情
        """
        from models.supply.supply_stock_detail import SupplyStockDetail
        from models.supply.stock_in_detail import StockInDetail
        from models.supply.stock_out_detail import StockOutDetail

        # 检查库存明细
        stock_count = SupplyStockDetail.query.filter_by(item_id=item_id).count()
        # 检查入库明细
        in_count = StockInDetail.query.filter_by(item_id=item_id).count()
        # 检查出库明细
        out_count = StockOutDetail.query.filter_by(item_id=item_id).count()

        used = stock_count > 0 or in_count > 0 or out_count > 0

        return {
            'used': used,
            'details': {
                'stock_detail_count': stock_count,
                'stock_in_count': in_count,
                'stock_out_count': out_count
            }
        }

    @classmethod

            SupplyStockDetail.item_id == item_id

            db.session.commit()
        return item

        return [item.name for item in items]
```

```python

from utils.db import db

class SupplyStockDetail(db.Model):
    """库存明细表 - 按物品+存放位置维度记录实时库存数量"""
    __tablename__ = 'supply_stock_details'

    id = db.Column(db.Integer, primary_key=True)

    # 关联字段

        ),

        db.Index('idx_ssd_location_id', 'location_id'),
        db.Index('idx_ssd_quantity', 'quantity'),
    )

        return f"<SupplyStockDetail item={self.item_id} location={self.location_id} qty={self.quantity}>"

    @property
    def item_name(self):
        """返回物品名称"""
        from models.supply.supply_item import SupplyItem
        item = SupplyItem.query.get(self.item_id)
        return item.name if item else '未知'

    @property
    def location_name(self):
        """返回位置名称"""
        from models.supply.storage_location import StorageLocation
        location = StorageLocation.query.get(self.location_id)
        return location.name if location else '未知'

    @classmethod
    def get_or_create(cls, item_id, location_id, operator_user_id=None):

                location_id=location_id,

                operator_user_id=operator_user_id

        增加库存（入库时调用）
        同时更新 SupplyItem.current_stock 汇总库存
        返回更新后的库存明细记录
        """
        from models.supply.supply_item import SupplyItem

        detail = cls.get_or_create(item_id, location_id, operator_user_id)
        detail.quantity += quantity
        detail.operator_user_id = operator_user_id

        # 同步更新物品汇总库存
        item = SupplyItem.query.get(item_id)
        if item:
            item.current_stock += quantity

        db.session.commit()
        return detail

    @classmethod
    def subtract_stock(cls, item_id, location_id, quantity, operator_user_id=None):
        """
        减少库存（出库时调用）
        同时更新 SupplyItem.current_stock 汇总库存
        如果库存不足，返回None并回滚
        返回更新后的库存明细记录
        """
        from models.supply.supply_item import SupplyItem

        detail = cls.query.filter_by(item_id=item_id, location_id=location_id).first()
        if not detail or detail.quantity < quantity:
            return None  # 库存不足

        detail.quantity -= quantity
        detail.operator_user_id = operator_user_id

        # 同步更新物品汇总库存
        item = SupplyItem.query.get(item_id)
        if item:
            item.current_stock -= quantity

        db.session.commit()
        return detail

        返回更新后的库存明细记录
        """
        from models.supply.supply_item import SupplyItem

        detail = cls.get_or_create(item_id, location_id, operator_user_id)
        old_quantity = detail.quantity
        detail.quantity = new_quantity
        detail.operator_user_id = operator_user_id

        # 同步更新物品汇总库存（差值调整）
        item = SupplyItem.query.get(item_id)

        return detail

        from models.supply.supply_item import SupplyItem
        low_items = SupplyItem.get_low_stock_items(company)
        item_ids = [item.id for item in low_items]
        if not item_ids:
            return []
        return cls.query.filter(cls.item_id.in_(item_ids)).order_by(cls.item_id, cls.location_id).all()
```

**设计说明**：
- **核心设计**：`item_id` + `location_id` 组成联合唯一约束 `uq_supply_stock_detail_item_location`，每个物品在每个位置只有一条记录
- **库存联动机制**：

  - `subtract_stock()`：出库时减少库存，库存不足时返回 `None`，同时更新汇总
  - `adjust_stock()`：盘点时调整到指定数量，差值更新汇总
- **quantity 非负约束**：`check_supply_stock_detail_quantity_non_negative` 确保库存数量不为负
- **get_or_create()**：获取或创建库存明细记录，首次入库到新位置时自动创建记录
- **查询方法**：`get_stock_by_item()`、`get_stock_by_location()` 分别按物品和位置维度查询库存
- 与 `SupplyItem` 的 `stock_details` 关系使用 `cascade='all, delete-orphan'`，删除物品时级联删除库存明细
- 与 `StorageLocation` 的 `stock_details` 关系使用 `cascade='all, delete-orphan'`，删除位置时级联删除库存明细

```python
            StockInDetail.quantity * StockInDetail.unit_price
        ), 0)).filter(StockInDetail.stock_in_id == stock_in_id).scalar()
        stock_in = cls.query.get(stock_in_id)
        if stock_in:
            stock_in.total_amount = total
            db.session.commit()
        return stock_in
```

**设计说明**：
- `stock_in_number` 自动生成，格式为 `RK+年月+4位序号`
- `status` 支持：待审核、已审核、已取消，使用检查约束限制
- `details` 关系使用 `cascade='all, delete-orphan'`，删除入库单时级联删除明细
- **审核联动**：`approve()` 方法审核通过时遍历明细，调用 `SupplyStockDetail.add_stock()` 增加库存，同时写入 `SupplyStockRecord` 记录

- `recalculate_total_amount()` 根据明细重新计算总金额

```python
            cls.inventory_number.like(prefix + '%')
        ).order_by(cls.inventory_number.desc()).first()

        if last and last.inventory_number.startswith(prefix):
            seq = int(last.inventory_number[len(prefix):]) + 1
        else:
            seq = 1
        return f'{prefix}{seq:04d}'

    def approve(cls, inventory_id, review_user_id, review_remark=None):
        """
        审核盘点单
        审核通过时：
        1. 更新盘点单状态为"已审核"
        2. 遍历盘点明细，更新 SupplyStockDetail（按位置调整库存到实盘数量）
        3. 遍历盘点明细，更新 SupplyItem.current_stock（差值调整汇总）
        4. 对有差异的明细，写入 SupplyStockRecord（盘点调整记录）
        """
        from models.supply.supply_stock_detail import SupplyStockDetail
        from models.supply.supply_stock_record import SupplyStockRecord

        inventory = cls.query.get(inventory_id)
        if not inventory or inventory.status != '待审核':
            return None

        inventory.status = '已审核'
        inventory.review_user_id = review_user_id
        inventory.review_time = datetime.now()
        inventory.review_remark = review_remark

        # 遍历盘点明细，调整库存
        for detail in inventory.details:
            old_quantity = detail.system_quantity
            new_quantity = detail.actual_quantity
            difference = new_quantity - old_quantity

            if difference != 0:
                # 更新库存明细（按位置调整到实盘数量）
                SupplyStockDetail.adjust_stock(
                    item_id=detail.item_id,
                    location_id=detail.location_id,
                    new_quantity=new_quantity,
                    operator_user_id=review_user_id
                )

                # 写入进出库记录（盘点调整）
                record_type = '盘盈' if difference > 0 else '盘亏'
                SupplyStockRecord.create_record(
                    record_type=record_type,
                    item_id=detail.item_id,
                    location_id=detail.location_id,
                    quantity=abs(difference),
                    unit_price=detail.unit_price,
                    source_number=inventory.inventory_number,
                    source_type='盘点调整',
                    operator_user_id=review_user_id,
                    remark=f'盘点单{inventory.inventory_number}审核通过，{record_type}{abs(difference)}件'
                )

        db.session.commit()
        return inventory

            return None
        inventory.status = '已取消'
        inventory.operator_user_id = operator_user_id
        db.session.commit()
        return inventory
```

```python
    def create_record(cls, record_type, item_id, location_id=None, location_name=None,
                      quantity=0, unit_price=0, source_number=None, source_type=None,
                      operator_user_id=None, recipient_user_id=None, department_id=None,
                      remark=None):
        """创建进出库记录"""
        from models.supply.supply_item import SupplyItem

        # 获取物品名称
        item = SupplyItem.query.get(item_id)
        item_name = item.name if item else '未知'

        # 获取位置名称
        if location_id and not location_name:
            from models.supply.storage_location import StorageLocation
            location = StorageLocation.query.get(location_id)
            location_name = location.name if location else '未知'

        record = cls(
            record_type=record_type,
            item_id=item_id,
            item_name=item_name,
            location_id=location_id,
            location_name=location_name,
            quantity=quantity,
            unit_price=unit_price,
            total_price=quantity * unit_price if unit_price else 0,
            source_number=source_number,
            source_type=source_type,
            operator_user_id=operator_user_id,
            recipient_user_id=recipient_user_id,
            department_id=department_id,
            remark=remark
        )
        db.session.add(record)
        db.session.commit()
        return record

    @classmethod
    def get_by_item(cls, item_id, start_date=None, end_date=None, record_type=None):
        """获取物品的进出库记录"""
        query = cls.query.filter_by(item_id=item_id)
        if start_date:
            query = query.filter(cls.record_date >= start_date)
        if end_date:
            query = query.filter(cls.record_date <= end_date)
        if record_type:
            query = query.filter_by(record_type=record_type)
        return query.order_by(cls.record_date.desc()).all()

    @classmethod
    def get_by_location(cls, location_id, start_date=None, end_date=None):
        """获取存放位置的进出库记录"""
        query = cls.query.filter_by(location_id=location_id)
        if start_date:
            query = query.filter(cls.record_date >= start_date)
        if end_date:
            query = query.filter(cls.record_date <= end_date)
        return query.order_by(cls.record_date.desc()).all()

    @classmethod
    def get_by_department(cls, department_id, start_date=None, end_date=None):
        """获取部门的领用记录"""
        query = cls.query.filter_by(department_id=department_id, record_type='出库')
        if start_date:
            query = query.filter(cls.record_date >= start_date)
        if end_date:
            query = query.filter(cls.record_date <= end_date)
        return query.order_by(cls.record_date.desc()).all()

    @classmethod
    def get_by_recipient(cls, recipient_user_id, start_date=None, end_date=None):
        """获取领用人的领用记录"""
        query = cls.query.filter_by(recipient_user_id=recipient_user_id, record_type='出库')
        if start_date:
            query = query.filter(cls.record_date >= start_date)
        if end_date:
            query = query.filter(cls.record_date <= end_date)
        return query.order_by(cls.record_date.desc()).all()

    @classmethod
    def get_statistics(cls, start_date=None, end_date=None, company=None):
        """获取进出库统计汇总"""
        from sqlalchemy import func

        query = db.session.query(
            cls.record_type,
            func.count(cls.id).label('count'),
            func.sum(cls.quantity).label('total_quantity'),
            func.sum(cls.total_price).label('total_amount')
        )

        if start_date:
            query = query.filter(cls.record_date >= start_date)
        if end_date:
            query = query.filter(cls.record_date <= end_date)

        return query.group_by(cls.record_type).all()
```

**设计说明**：
- **新增 `location_id` 和 `location_name` 字段**：记录每笔进出库操作对应的存放位置
- `record_type` 支持：入库、出库、盘盈、盘亏，使用检查约束限制
- `item_name`、`location_name` 为冗余存储，避免物品/位置信息变更后历史数据丢失
- `location_id` 外键使用 `ondelete='SET NULL'`，位置删除后记录保留但位置字段置空
- `recipient_user_id` 和 `department_id` 仅出库时记录，关联用户和部门表
- `source_number` 和 `source_type` 记录来源单据信息，便于追溯
- `quantity` 始终为正数，通过 `record_type` 区分增减方向
- 多种查询方法：按物品、按位置、按部门、按领用人查询，支持日期范围过滤
- `get_statistics()` 提供按类型分组的统计汇总

```python
from flask import request, redirect, url_for, flash, jsonify
from flask_login import login_required, current_user
from utils.auth import admin_required
from utils.log import log_operation
from models.supply.stock_in import StockIn
from models.supply.stock_in_detail import StockInDetail
from .stock_in import stock_in_bp

@stock_in_bp.route('/operations/add', methods=['POST'])
@login_required
@admin_required
def add_stock_in_post():
    """新增入库单操作（含明细）"""
    stock_in_type = request.form.get('stock_in_type')
    stock_in_date = request.form.get('stock_in_date')
    supplier_id = request.form.get('supplier_id', type=int)
    handler_user_id = request.form.get('handler_user_id', type=int)
    company = request.form.get('company', '').strip()
    remark = request.form.get('remark', '').strip()

    # 创建入库主表
    stock_in = StockIn.create(
        stock_in_type=stock_in_type,
        stock_in_date=stock_in_date,
        supplier_id=supplier_id,
        handler_user_id=handler_user_id,
        company=company,
        remark=remark,
        operator_user_id=current_user.id
    )

    # 解析并创建入库明细（前端动态添加明细行）
    item_ids = request.form.getlist('item_id[]')
    location_ids = request.form.getlist('location_id[]')
    quantities = request.form.getlist('quantity[]')
    unit_prices = request.form.getlist('unit_price[]')

    for i in range(len(item_ids)):
        if item_ids[i] and location_ids[i] and quantities[i]:
            detail = StockInDetail.create(
                stock_in_id=stock_in.id,
                item_id=int(item_ids[i]),
                item_name=request.form.getlist('item_name[]')[i],
                location_id=int(location_ids[i]),
                location_name=request.form.getlist('location_name[]')[i],
                quantity=int(quantities[i]),
                unit_price=float(unit_prices[i]) if unit_prices[i] else 0,
                specification=request.form.getlist('specification[]')[i] if i < len(request.form.getlist('specification[]')) else None,
                unit=request.form.getlist('unit[]')[i] if i < len(request.form.getlist('unit[]')) else None,
                operator_user_id=current_user.id
            )

    # 重新计算总金额
    StockIn.recalculate_total_amount(stock_in.id)

    log_operation('新增入库单', f'新增入库单：{stock_in.stock_in_number}')
    flash('入库单创建成功', 'success')
    return redirect(url_for('stock_in.stock_in_detail', id=stock_in.id))

@stock_in_bp.route('/operations/approve/<int:id>', methods=['POST'])
@login_required
@admin_required
def approve_stock_in(id):
    """审核入库单操作

    审核通过时：
    1. 更新入库单状态为"已审核"
    2. 遍历入库明细，更新 SupplyStockDetail（按位置增加库存）
    3. 遍历入库明细，更新 SupplyItem.current_stock（汇总增加）
    4. 遍历入库明细，写入 SupplyStockRecord（入库记录）
    """
    review_remark = request.form.get('review_remark', '').strip()
    result = StockIn.approve(id, review_user_id=current_user.id, review_remark=review_remark)

    if result:
        log_operation('审核入库单', f'审核入库单：{result.stock_in_number}')
        flash('入库单审核成功，库存已更新', 'success')
    else:
        flash('入库单审核失败', 'error')
    return redirect(url_for('stock_in.stock_in_detail', id=id))

        flash('入库单已取消', 'success')

        flash('入库单取消失败（仅待审核状态可取消）', 'error')
```

### 9.5 库存联动机制汇总

| 操作 | SupplyStockDetail | SupplyItem.current_stock | SupplyStockRecord |
|------|-------------------|-------------------------|-------------------|
| 入库审核通过 | `add_stock()` 按位置增加 | 汇总增加 | 写入"入库"记录 |
| 出库审核通过 | `subtract_stock()` 按位置减少（先检查库存） | 汇总减少 | 写入"出库"记录 |
| 盘点审核通过 | `adjust_stock()` 按位置调整到实盘数量 | 差值调整 | 有差异时写入"盘盈"/"盘亏"记录 |
| 手动重新计算 | `recalculate_stock()` 从明细聚合 | 重算为聚合值 | 不写入记录 |

**数据一致性保证**：
1. 所有库存更新操作在同一个数据库事务中执行（`db.session.commit()` 一次性提交）
2. `SupplyStockDetail` 和 `SupplyItem.current_stock` 在同一事务中同步更新
3. 出库审核时先检查所有明细库存是否充足，不足时整个审核失败回滚
4. `SupplyItem.recalculate_stock()` 可用于数据校验和修复，从 `SupplyStockDetail` 重新聚合计算

```python
    def generate_stock_out_number(cls):

        prefix = 'CK' + datetime.now().strftime('%Y%m')
        last = cls.query.filter(
            cls.stock_out_number.like(prefix + '%')
        ).order_by(cls.stock_out_number.desc()).first()

        if last and last.stock_out_number.startswith(prefix):
            seq = int(last.stock_out_number[len(prefix):]) + 1
        else:

    @classmethod
    def approve(cls, stock_out_id, review_user_id, review_remark=None):
        """
        审核出库单
        审核通过时：
        1. 检查每个明细的库存是否充足（按位置检查 SupplyStockDetail）
        2. 更新出库单状态为"已审核"
        3. 遍历出库明细，更新 SupplyStockDetail（按位置减少库存）
        4. 遍历出库明细，更新 SupplyItem.current_stock（汇总减少）
        5. 遍历出库明细，写入 SupplyStockRecord（出库记录）
        如果任何明细库存不足，审核失败并返回错误信息
        """
        from models.supply.supply_stock_detail import SupplyStockDetail
        from models.supply.supply_stock_record import SupplyStockRecord

        stock_out = cls.query.get(stock_out_id)
        if not stock_out or stock_out.status != '待审核':
            return None

        # 先检查所有明细的库存是否充足
        insufficient_items = []
        for detail in stock_out.details:
            stock_detail = SupplyStockDetail.query.filter_by(
                item_id=detail.item_id,
                location_id=detail.location_id
            ).first()
            if not stock_detail or stock_detail.quantity < detail.quantity:
                insufficient_items.append({
                    'item_name': detail.item_name,
                    'location_name': detail.location_name,
                    'available': stock_detail.quantity if stock_detail else 0,
                    'required': detail.quantity
                })

        if insufficient_items:
            return {'error': '库存不足', 'details': insufficient_items}

        # 库存充足，执行出库
        stock_out.status = '已审核'
        stock_out.review_user_id = review_user_id
        stock_out.review_time = datetime.now()
        stock_out.review_remark = review_remark

        for detail in stock_out.details:
            # 更新库存明细（按位置减少）
            SupplyStockDetail.subtract_stock(
                item_id=detail.item_id,
                location_id=detail.location_id,
                quantity=detail.quantity,
                operator_user_id=review_user_id
            )
            # 写入进出库记录
            SupplyStockRecord.create_record(
                record_type='出库',
                item_id=detail.item_id,
                location_id=detail.location_id,
                quantity=detail.quantity,
                unit_price=detail.unit_price,
                source_number=stock_out.stock_out_number,
                source_type=stock_out.stock_out_type,
                operator_user_id=review_user_id,
                recipient_user_id=stock_out.recipient_user_id,
                department_id=stock_out.department_id,
                remark=f'出库单{stock_out.stock_out_number}审核通过'
            )

        db.session.commit()
        return stock_out

    @classmethod
    def cancel(cls, stock_out_id, operator_user_id=None):
        """取消出库单（仅待审核状态可取消）"""
        stock_out = cls.query.get(stock_out_id)
        if not stock_out or stock_out.status != '待审核':
            return None
        stock_out.status = '已取消'
        stock_out.operator_user_id = operator_user_id
        db.session.commit()
        return stock_out

    @classmethod
    def recalculate_total_amount(cls, stock_out_id):
        """根据明细重新计算出库总金额"""
        from sqlalchemy import func
        total = db.session.query(func.coalesce(func.sum(
            StockOutDetail.quantity * StockOutDetail.unit_price
        ), 0)).filter(StockOutDetail.stock_out_id == stock_out_id).scalar()
        stock_out = cls.query.get(stock_out_id)
        if stock_out:
            stock_out.total_amount = total
            db.session.commit()
        return stock_out
```

**设计说明**：
- `stock_out_number` 自动生成，格式为 `CK+年月+4位序号`
- `recipient_user_id` 领用人、`department_id` 领用部门，与用户管理和部门管理模块集成
- **审核联动**：`approve()` 方法先检查所有明细库存是否充足，再执行出库。库存不足时返回错误详情
- 出库审核时调用 `SupplyStockDetail.subtract_stock()` 减少库存，同时写入 `SupplyStockRecord` 记录

```python
    inventory_id = db.Column(db.Integer, db.ForeignKey('supply_inventories.id', ondelete='CASCADE'), nullable=False, comment='盘点主表ID')

    # 物品关联
    item_id = db.Column(db.Integer, db.ForeignKey('supply_items.id', ondelete='RESTRICT'), nullable=False, comment='物品ID')
    item_name = db.Column(db.String(200), nullable=False, comment='物品名称（冗余存储）')
    specification = db.Column(db.String(200), nullable=True, comment='规格型号（冗余存储）')
    unit = db.Column(db.String(20), nullable=True, comment='计量单位（冗余存储）')

    # 存放位置
    location_id = db.Column(db.Integer, db.ForeignKey('storage_locations.id', ondelete='RESTRICT'), nullable=False, comment='盘点存放位置ID')
    location_name = db.Column(db.String(200), nullable=False, comment='存放位置名称（冗余存储）')

    # 盘点数量
    system_quantity = db.Column(db.Integer, nullable=False, comment='系统数量（盘点时的账面库存）')
    actual_quantity = db.Column(db.Integer, nullable=False, comment='实盘数量（实际盘点数量）')
    difference_quantity = db.Column(db.Integer, nullable=False, comment='差异数量（实盘-系统）')

    # 价格信息
    unit_price = db.Column(db.Numeric(10, 2), default=0, nullable=False, comment='单价（用于计算差异金额）')

    # 备注
    remark = db.Column(db.Text, nullable=True, comment='备注信息')

    # 操作用户
    operator_user_id = db.Column(db.Integer, nullable=True, comment='操作用户ID')

    # 时间记录
    created_at = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='创建时间')
    updated_at = db.Column(db.DateTime, default=datetime.now, onupdate=datetime.now, nullable=False, comment='更新时间')

    # 约束与索引
    __table_args__ = (
        db.CheckConstraint(
            "system_quantity >= 0",
            name='check_supply_inventory_detail_system_qty_non_negative'
        ),
        db.CheckConstraint(
            "actual_quantity >= 0",
            name='check_supply_inventory_detail_actual_qty_non_negative'
        ),
        db.Index('idx_sid_inventory_id', 'inventory_id'),
        db.Index('idx_sid_item_id', 'item_id'),
        db.Index('idx_sid_location_id', 'location_id'),
    )

    def __repr__(self):
        return f"<SupplyInventoryDetail inventory={self.inventory_id} item={self.item_name} diff={self.difference_quantity}>"

    @property
    def difference_amount(self):
        """计算差异金额"""
        return self.difference_quantity * self.unit_price

    @property
    def is_matched(self):
        """是否账实相符"""
        return self.difference_quantity == 0

    @classmethod
    def create(cls, inventory_id, item_id, item_name, location_id, location_name,
               system_quantity, actual_quantity, unit_price=0,
               specification=None, unit=None,
               remark=None, operator_user_id=None):

        detail = cls(
            inventory_id=inventory_id,
            item_id=item_id,
            item_name=item_name,
            specification=specification,
            unit=unit,
            location_id=location_id,
            location_name=location_name,
            system_quantity=system_quantity,
            actual_quantity=actual_quantity,
            difference_quantity=actual_quantity - system_quantity,
            unit_price=unit_price,
            remark=remark,
            operator_user_id=operator_user_id
        )
        db.session.add(detail)
        db.session.commit()
        return detail

    @classmethod
    def get_by_inventory(cls, inventory_id):
        """获取盘点单的所有明细"""
        return cls.query.filter_by(inventory_id=inventory_id).order_by(cls.id).all()

    @classmethod
    def get_difference_details(cls, inventory_id):
        """获取有差异的盘点明细"""
        return cls.query.filter(
            cls.inventory_id == inventory_id,
            cls.difference_quantity != 0
        ).order_by(cls.id).all()
```

**设计说明**：
- **新增 `location_id` 和 `location_name` 字段**：盘点时按物品+存放位置维度进行盘点
- `system_quantity`：系统账面库存（从 `SupplyStockDetail` 获取）
- `actual_quantity`：实盘数量（人工盘点后填入）
- `difference_quantity`：差异数量 = `actual_quantity` - `system_quantity`，创建时自动计算
- `difference_amount` 属性方法计算差异金额 = `difference_quantity` × `unit_price`
- `is_matched` 属性方法判断是否账实相符（差异为0）
- `item_id` 和 `location_id` 外键均使用 `ondelete='RESTRICT'`

- `GET /supply-stock-record/by-item/<item_id>` - 按物品查看进出库记录
- `GET /supply-stock-record/by-location/<location_id>` - 按位置查看进出库记录
- `GET /supply-stock-record/by-department/<department_id>` - 按部门查看领用记录
- `GET /supply-stock-record/by-recipient/<user_id>` - 按领用人查看领用记录
- `GET /supply-stock-record/statistics` - 进出库统计汇总页

API蓝图: `blueprints/supply/supply_stock_record_api.py`（`supply_stock_record_api_bp`, URL前缀 `/api/supply-stock-records`）

> **说明**：进出库记录由系统自动维护（入库/出库/盘点审核时自动写入），不支持手动新增/编辑/删除，也不支持导入导出

```javascript
    const rowIndex = document.querySelectorAll('.detail-row').length;
    const row = document.createElement('tr');
    row.className = 'detail-row';
    row.innerHTML = `
        <td><select name="item_id[]" onchange="onItemSelect(this, ${rowIndex})" required>
            <option value="">请选择物品</option>

        </select></td>

        <td><button type="button" onclick="removeRow(this)">删除</button></td>
    `;
    document.getElementById('detail-tbody').appendChild(row);

// 选择物品后自动填充信息
function onItemSelect(select, rowIndex) {
    const itemId = select.value;
    fetch(`/api/supply-items/${itemId}`)
        .then(res => res.json())
        .then(data => {
            document.getElementsByName('item_name[]')[rowIndex].value = data.name;
            document.getElementsByName('specification[]')[rowIndex].value = data.specification || '';
            document.getElementsByName('unit[]')[rowIndex].value = data.unit || '';
            document.getElementsByName('unit_price[]')[rowIndex].value = data.unit_price || 0;
        });
}
```

```javascript
function onLocationSelect(select, rowIndex) {
    const itemId = document.getElementsByName('item_id[]')[rowIndex].value;
    const locationId = select.value;
    if (itemId && locationId) {
        fetch(`/api/supply-stock-details/by-item/${itemId}`)
            .then(res => res.json())
            .then(data => {
                const stock = data.find(d => d.location_id == locationId);
                const maxQty = stock ? stock.quantity : 0;
                const qtyInput = document.getElementsByName('quantity[]')[rowIndex];
                qtyInput.max = maxQty;
                document.getElementById(`stock-info-${rowIndex}`).textContent = `当前库存: ${maxQty}`;
            });
    }
}
```

### 9.5 库存联动机制汇总

| 操作 | SupplyStockDetail | SupplyItem.current_stock | SupplyStockRecord |
|------|-------------------|-------------------------|-------------------|
| 入库审核通过 | `add_stock()` 按位置增加 | 汇总增加 | 写入"入库"记录 |
| 出库审核通过 | `subtract_stock()` 按位置减少（先检查库存） | 汇总减少 | 写入"出库"记录 |
| 盘点审核通过 | `adjust_stock()` 按位置调整到实盘数量 | 差值调整 | 有差异时写入"盘盈"/"盘亏"记录 |
| 手动重新计算 | `recalculate_stock()` 从明细聚合 | 重算为聚合值 | 不写入记录 |

**数据一致性保证**：
1. 所有库存更新操作在同一个数据库事务中执行（`db.session.commit()` 一次性提交）
2. `SupplyStockDetail` 和 `SupplyItem.current_stock` 在同一事务中同步更新
3. 出库审核时先检查所有明细库存是否充足，不足时整个审核失败回滚
4. `SupplyItem.recalculate_stock()` 可用于数据校验和修复，从 `SupplyStockDetail` 重新聚合计算
