# 固定资产管理模块设计方案

## 一、模块概述

基于现有行政后勤管理系统架构，新增固定资产管理模块，实现固定资产的全生命周期管理，包括资产登记、编辑、查看、转移、盘点、报废、出售、导入导出等功能。所有增加、修改、转移、盘点、报废、出售操作均需记录操作日志。删除资产时需联动删除关联记录及磁盘照片文件。

## 二、架构设计原则

严格遵循项目现有架构模式：
- **Blueprint分层模式**: 主蓝图(列表页+筛选+分页) / 操作蓝图(CRUD) / API蓝图(JSON响应+媒体服务) / 导入导出蓝图(pandas+openpyxl)
- **模型设计模式**: __table_args__(约束+索引) + @property属性方法 + @classmethod类方法
- **配置驱动**: 资产分类、资产状态等从SystemConfig读取
- **操作日志**: 同时调用log_operation写入OperationLog，并写入专用AssetOperationRecord记录变更详情
- **照片存储**: 参照RoomPhotoManager创建AssetPhotoManager，支持Docker/PyInstaller/开发三种环境
- **权限控制**: admin_required装饰器 + login_required认证
- **前端技术栈**: TailwindCSS + FontAwesome + Jinja2模板

### 3.1 固定资产主表 - FixedAsset

文件: `models/fixed_asset.py`

```python
from datetime import datetime
from decimal import Decimal
from utils.db import db

class FixedAsset(db.Model):
    """固定资产主表"""
    __tablename__ = 'fixed_assets'
    
    # 核心字段
    id = db.Column(db.Integer, primary_key=True)
    asset_number = db.Column(db.String(50), unique=True, nullable=True, comment='资产编号（允许自定义，留空自动生成）')
    asset_name = db.Column(db.String(255), nullable=False, comment='资产名称')
    asset_category = db.Column(db.String(50), nullable=False, comment='资产分类（从系统配置读取）')
    
    # 规格与价值
    specification = db.Column(db.String(255), nullable=True, comment='规格型号')
    brand = db.Column(db.String(100), nullable=True, comment='品牌')
    quantity = db.Column(db.Integer, default=1, nullable=False, comment='数量')
    unit = db.Column(db.String(20), default='台', nullable=True, comment='单位')
    original_value = db.Column(db.Numeric(12, 2), default=Decimal('0.00'), nullable=True, comment='原值（元）')
    net_value = db.Column(db.Numeric(12, 2), default=Decimal('0.00'), nullable=True, comment='净值（元）')
    
    # 日期信息
    purchase_date = db.Column(db.Date, nullable=True, comment='购置日期')
    warranty_expiry = db.Column(db.Date, nullable=True, comment='质保到期日')
    
    # 位置信息（自由文本输入，不限制）
    storage_location = db.Column(db.String(500), nullable=True, comment='存放位置（自由输入）')
    
    # 部门信息
    department_using = db.Column(db.String(100), nullable=True, comment='使用部门')
    department_owning = db.Column(db.String(100), nullable=True, comment='归属部门')
    
    # 责任人
    responsible_person = db.Column(db.String(50), nullable=True, comment='责任人')
    
    # 来源与状态
    asset_source = db.Column(db.String(20), default='采购', comment='资产来源')
    status = db.Column(db.String(20), default='在用', nullable=False, comment='资产状态')
    
    # 备注
    remark = db.Column(db.Text, nullable=True, comment='备注信息')
    
    # 报废信息
    scrap_date = db.Column(db.Date, nullable=True, comment='报废日期')
    scrap_reason = db.Column(db.Text, nullable=True, comment='报废原因')
    
    # 出售信息
    sale_date = db.Column(db.Date, nullable=True, comment='出售日期')
    sale_price = db.Column(db.Numeric(12, 2), nullable=True, comment='出售金额（元）')
    sale_buyer = db.Column(db.String(255), nullable=True, comment='买方信息')
    
    # 操作用户
    operator_user_id = db.Column(db.Integer, nullable=True, comment='操作用户ID')
    
    # 时间记录
    created_at = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='创建时间')
    updated_at = db.Column(db.DateTime, default=datetime.now, onupdate=datetime.now, nullable=False, comment='更新时间')
    
    # 关系定义
    operation_records = db.relationship('AssetOperationRecord', backref='asset', lazy=True, cascade='all, delete-orphan')
    inventory_details = db.relationship('AssetInventoryDetail', backref='asset', lazy=True, cascade='all, delete-orphan')
    
    # 删除联动说明：删除资产时，数据库级联删除 operation_records 和 inventory_details；
    # 磁盘上的照片文件需在删除路由中显式调用 AssetPhotoManager.delete_all_files(asset_id) 清理照片目录。
    # 删除操作仅写入 OperationLog(module='asset') 记录摘要，因为 AssetOperationRecord 会被级联删除。
    
    # 约束与索引
    __table_args__ = (
        db.CheckConstraint('quantity > 0', name='check_quantity_positive'),
        db.CheckConstraint(
            "status IN ('在用', '闲置', '维修中', '已报废', '已转移', '已出售')",
            name='check_asset_status_valid'
        ),
        db.CheckConstraint(
            "asset_source IN ('采购', '捐赠', '调入', '自建', '其他')",
            name='check_asset_source_valid'
        ),
        db.Index('idx_asset_number', 'asset_number'),
        db.Index('idx_asset_category', 'asset_category'),
        db.Index('idx_asset_status', 'status'),
        db.Index('idx_asset_dept_using', 'department_using'),
        db.Index('idx_asset_dept_owning', 'department_owning'),
        db.Index('idx_asset_location', 'storage_location'),
        db.Index('idx_asset_purchase_date', 'purchase_date'),
        db.Index('idx_asset_scrap_date', 'scrap_date'),
        db.Index('idx_asset_sale_date', 'sale_date'),
    )
    
    def __repr__(self):
        return f"<FixedAsset {self.asset_number or self.id}: {self.asset_name}>"
    
    @property
    def display_number(self):
        """返回资产编号，若为空则返回自增ID格式"""
        return self.asset_number or f"ZC{self.id:06d}"
    
    @classmethod
    def generate_asset_number(cls):
        """自动生成资产编号：ZC + 年月 + 4位序号"""
        today = datetime.now()
        prefix = f"ZC{today.strftime('%Y%m')}"
        last_asset = cls.query.filter(
            cls.asset_number.like(f"{prefix}%")
        ).order_by(cls.id.desc()).first()
        if last_asset and last_asset.asset_number:
            try:
                seq = int(last_asset.asset_number[-4:]) + 1
            except ValueError:
                seq = 1
        else:
            seq = 1
        return f"{prefix}{seq:04d}"
    
    @classmethod
    def create(cls, asset_number=None, asset_name=None, asset_category=None, 
               specification=None, brand=None, quantity=1, unit='台',
               original_value=None, net_value=None, purchase_date=None,
               warranty_expiry=None, storage_location=None,
               department_using=None, department_owning=None,
               responsible_person=None, asset_source=None, status=None,
               remark=None, operator_user_id=None):
        """创建固定资产"""
        asset = cls(
            asset_number=asset_number,
            asset_name=asset_name,
            asset_category=asset_category,
            specification=specification,
            brand=brand,
            quantity=quantity,
            unit=unit,
            original_value=original_value or Decimal('0.00'),
            net_value=net_value or Decimal('0.00'),
            purchase_date=purchase_date,
            warranty_expiry=warranty_expiry,
            storage_location=storage_location,
            department_using=department_using,
            department_owning=department_owning,
            responsible_person=responsible_person,
            asset_source=asset_source or '采购',
            status=status or '在用',
            remark=remark,
            operator_user_id=operator_user_id
        )
        db.session.add(asset)
        db.session.flush()  # 获取ID用于自动编号
        if not asset.asset_number:
            asset.asset_number = cls.generate_asset_number()
        db.session.commit()
        return asset
```

### 3.2 资产操作记录表 - AssetOperationRecord

文件: `models/asset_operation_record.py`

```python
from datetime import datetime
from utils.db import db

class AssetOperationRecord(db.Model):
    """资产操作记录表 - 记录所有增加/修改/转移/盘点操作的详细变更"""
    __tablename__ = 'asset_operation_records'
    
    id = db.Column(db.Integer, primary_key=True)
    asset_id = db.Column(db.Integer, db.ForeignKey('fixed_assets.id', ondelete='CASCADE'), nullable=False, comment='关联资产ID')
    operation_type = db.Column(db.String(20), nullable=False, comment='操作类型：add/edit/transfer/inventory/scrap/sell/delete')
    operator_id = db.Column(db.Integer, nullable=True, comment='操作人ID')
    operator_name = db.Column(db.String(50), nullable=True, comment='操作人姓名')
    operation_time = db.Column(db.DateTime, default=datetime.now, nullable=False, comment='操作时间')
    
    # 变更详情（JSON格式，记录变更前后值）
    change_detail = db.Column(db.Text, nullable=True, comment='变更详情（JSON格式）')
    # 示例: {"field": "status", "old_value": "在用", "new_value": "闲置"}
    # 编辑操作: [{"field": "asset_name", "old": "电脑", "new": "笔记本电脑"}, {"field": "status", "old": "在用", "new": "闲置"}]
    # 转移操作: {"from_location": "A楼", "to_location": "B楼", "from_dept_using": "部门1", "to_dept_using": "部门2", "from_responsible": "张三", "to_responsible": "李四"}
    # 盘点操作: {"inventory_id": 1, "result": "正常", "remark": "盘点确认"}
    
    # 操作摘要（便于快速查看）
    summary = db.Column(db.String(500), nullable=True, comment='操作摘要')
    
    # 索引
    __table_args__ = (
        db.Index('idx_aor_asset_id', 'asset_id'),
        db.Index('idx_aor_operation_type', 'operation_type'),
        db.Index('idx_aor_operation_time', 'operation_time'),
        db.Index('idx_aor_asset_time', 'asset_id', 'operation_time'),
    )
    
    def __repr__(self):
        return f"<AssetOperationRecord asset={self.asset_id} type={self.operation_type}>"
    
    @classmethod
    def create_record(cls, asset_id, operation_type, operator_id=None, 
                      operator_name=None, change_detail=None, summary=None):
        """创建操作记录"""
        import json
        record = cls(
            asset_id=asset_id,
            operation_type=operation_type,
            operator_id=operator_id,
            operator_name=operator_name,
            change_detail=json.dumps(change_detail, ensure_ascii=False) if isinstance(change_detail, dict) else change_detail,
            summary=summary
        )
        db.session.add(record)
        db.session.commit()
        return record
```

### 4.3 操作蓝图路由设计 - fixed_asset_operations_bp

文件: `blueprints/fixed_asset_operations.py`

| 路由 | 方法 | 功能 | 操作记录 | 权限 |
|------|------|------|---------|------|
| `/fixed_asset/operations/add` | POST | 新增资产 | AssetOperationRecord(type='add') + log_operation | admin_required |
| `/fixed_asset/operations/edit/<int:id>` | POST | 编辑资产 | AssetOperationRecord(type='edit', 记录变更字段前后值) + log_operation | admin_required |
| `/fixed_asset/operations/delete/<int:id>` | POST | 删除资产 | log_operation(module='asset')记录摘要；级联删除关联记录；显式删除磁盘照片 | admin_required |
| `/fixed_asset/operations/batch-delete` | POST | 批量删除 | log_operation | admin_required |
| `/fixed_asset/operations/transfer/<int:id>` | POST | 资产转移 | AssetOperationRecord(type='transfer', 记录转移前后位置/部门/责任人) + log_operation | admin_required |
| `/fixed_asset/operations/inventory/create` | POST | 创建盘点单 | AssetOperationRecord(type='inventory') + log_operation | admin_required |
| `/fixed_asset/operations/inventory/check` | POST | 执行盘点（逐条确认） | AssetOperationRecord(type='inventory', 记录盘点结果) | admin_required |
| `/fixed_asset/operations/inventory/complete/<int:id>` | POST | 完成盘点 | log_operation | admin_required |
| `/fixed_asset/operations/scrap/<int:id>` | POST | 执行报废 | AssetOperationRecord(type='scrap', 记录报废日期和原因) + log_operation | admin_required |
| `/fixed_asset/operations/sell/<int:id>` | POST | 执行出售 | AssetOperationRecord(type='sell', 记录出售日期/金额/买方) + log_operation | admin_required |

**操作记录策略**:
- **新增**: 记录完整资产信息到change_detail，summary="新增资产: {asset_name}"
- **编辑**: 逐字段对比，仅记录变更字段到change_detail（JSON数组），summary="编辑资产: {asset_name}，修改了{字段列表}"
- **转移**: 记录转移前后位置、部门和责任人，summary="资产转移: {asset_name}，从{原位置}转移到{新位置}"
- **盘点**: 记录盘点结果，summary="资产盘点: {asset_name}，结果: {正常/异常}"
- **报废**: 记录报废日期和原因到change_detail，summary="资产报废: {asset_name}，原因: {scrap_reason}"
- **出售**: 记录出售日期、金额、买方到change_detail，summary="资产出售: {asset_name}，金额: {sale_price}元，买方: {sale_buyer}"
- **删除**: 仅写入OperationLog(module='asset')记录摘要（因为AssetOperationRecord会被级联删除），同时在删除路由中显式调用AssetPhotoManager.delete_all_files(asset_id)清理磁盘照片

## 十一、操作记录详细设计

### 11.1 双重记录策略

每次资产操作同时写入两套记录:

1. **OperationLog（通用操作日志）**: 调用 `log_operation()` 函数，module='asset'，记录操作摘要，用于全局日志查看
2. **AssetOperationRecord（专用操作记录）**: 记录变更详情（JSON），用于资产详情页的操作时间线展示

### 11.2 各操作类型的记录内容

**新增(add)**:
```json
{
    "asset_number": "ZC2026080001",
    "asset_name": "联想笔记本电脑",
    "asset_category": "电子设备",
    "specification": "ThinkPad X1 Carbon",
    "storage_location": "A栋3楼办公室",
    "department_using": "技术部",
    "department_owning": "行政部",
    "status": "在用"
}
```
summary: "新增资产: 联想笔记本电脑"

**编辑(edit)**: 仅记录变更字段
```json
[
    {"field": "asset_name", "old": "电脑", "new": "联想笔记本电脑"},
    {"field": "status", "old": "在用", "new": "维修中"}
]
```
summary: "编辑资产: 联想笔记本电脑，修改了资产名称、状态"

**转移(transfer)**:
```json
{
    "from_location": "A栋3楼办公室",
    "to_location": "B栋1楼仓库",
    "from_department_using": "技术部",
    "to_department_using": "运营部",
    "from_department_owning": "行政部",
    "to_department_owning": "行政部",
    "from_responsible_person": "张三",
    "to_responsible_person": "李四",
    "reason": "部门调整"
}
```
summary: "资产转移: 联想笔记本电脑，从A栋3楼办公室转移到B栋1楼仓库，责任人: 张三→李四"

**盘点(inventory)**:
```json
{
    "inventory_id": 1,
    "inventory_number": "PD2026080001",
    "result": "正常",
    "remark": "实物与台账一致"
}
```
summary: "资产盘点: 联想笔记本电脑，结果: 正常"

**报废(scrap)**:
```json
{
    "scrap_date": "2026-08-26",
    "scrap_reason": "设备老化，无法维修",
    "old_status": "维修中",
    "new_status": "已报废"
}
```
summary: "资产报废: 联想笔记本电脑，原因: 设备老化，无法维修"

**出售(sell)**:
```json
{
    "sale_date": "2026-08-26",
    "sale_price": 1500.00,
    "sale_buyer": "某某公司",
    "old_status": "闲置",
    "new_status": "已出售"
}
```
summary: "资产出售: 联想笔记本电脑，金额: 1500.00元，买方: 某某公司"

**删除(delete)**:
删除操作仅写入OperationLog(module='asset')记录摘要，不写入AssetOperationRecord（因为AssetOperationRecord会被数据库级联删除）。删除路由中需显式调用AssetPhotoManager.delete_all_files(asset_id)清理磁盘照片目录。
```json
{
    "asset_number": "ZC2026080001",
    "asset_name": "联想笔记本电脑",
    "asset_category": "电子设备"
}
```
OperationLog摘要: "删除资产: 联想笔记本电脑(ZC2026080001)"
